# 0.10.5 — Claude Code tool arguments arrive whole

A Claude Code tool call now carries its full arguments. Before this release, a
long file write lost its middle before a consumer saw it.

## Highlights

- **Claude Code tool arguments arrive whole.** Upstream `adr-sensor` cuts each
  string argument over 1,000 characters to its first and last 400 characters.
  A file tool's content is an argument, so the cut removed what the call wrote.
  The Claude Code reader now reads each call's input from the `tool_use` block
  of its own record. Where it cannot find that record, it uses upstream's
  abridged copy, and upstream's marker stays in each value that upstream cut.
  The Codex, Cursor and Devin readers did not have this gap.
- **The Cursor IDE log reader drops a list that nothing read.** The list held
  ids that the reader already keeps on open turns, requests and errors. It
  grew for the life of each log file and changed no session.

## Install

`uv tool install openaidr==0.10.5` or `pip install openaidr==0.10.5`.

## Compatibility

Beta, no back-compat guarantee before 1.0.

- **Claude Code argument values change.** A string argument over 1,000
  characters now holds its full text. The fallback path keeps upstream's
  abridged copy and truncation marker instead.
- **No span-identity change.** Session IDs, span IDs, agent kinds, the
  `(server, tool)` split and the `Session` fields are the same as in 0.10.4.
- **Dependencies are unchanged.**
