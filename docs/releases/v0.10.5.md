# 0.10.5 — The Cursor IDE log reader keeps less state

The Cursor IDE log reader no longer keeps a list of conversation ids for the
life of each log file.

## Highlights

- **The Cursor IDE log reader drops a list that nothing read.** The list held
  ids that the reader already keeps on open turns, requests and errors. It
  grew for the life of each log file and changed no session.

## Install

`uv tool install openaidr==0.10.5` or `pip install openaidr==0.10.5`.

## Compatibility

Beta, no back-compat guarantee before 1.0.

- **No span-identity change.** Session IDs, span IDs, agent kinds, the
  `(server, tool)` split and the `Session` fields are the same as in 0.10.4.
- **Dependencies are unchanged.**
