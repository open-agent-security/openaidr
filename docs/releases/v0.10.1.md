# 0.10.1 — No package change

This release changes no code that the package ships. It publishes the
repository state after 0.10.0, so that a consumer that pins the newest release
tracks `main`.

## Highlights

- **No change to the session model, the readers or span identity.** The
  commits since 0.10.0 change test fixtures and repository automation only.

## Install

`uv tool install openaidr==0.10.1` or `pip install openaidr==0.10.1`.

## Compatibility

Beta, no back-compat guarantee before 1.0.

- **Nothing changes for a consumer.** Session IDs, span IDs, agent kinds, the
  `(server, tool)` split and the `Session` fields are the same as in 0.10.0.
- **Dependencies are unchanged.**
