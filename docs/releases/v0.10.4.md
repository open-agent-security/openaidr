# 0.10.4 — `Session.originator` stays on the machine

`Session.originator` is now in `LOCAL_ONLY`, as ADR-0040 says it is.

## Highlights

- **`Session.originator` is in `LOCAL_ONLY`.** The native client name is a
  client-controlled string, and it can name a person or a host. It already
  stayed out of the public descriptor and the JSON output. A consumer that
  withholds the `LOCAL_ONLY` fields still shipped it, because the field was
  not in the set. Now it is (ADR-0040).

## Install

`uv tool install openaidr==0.10.4` or `pip install openaidr==0.10.4`.

## Compatibility

Beta, no back-compat guarantee before 1.0.

- **`LOCAL_ONLY` has one more field.** A consumer that withholds the
  `LOCAL_ONLY` fields now withholds `originator` too.
- **No span-identity change.** Session IDs, span IDs, agent kinds, the
  `(server, tool)` split and the `Session` fields are the same as in 0.10.3.
- **Dependencies are unchanged.**
