# 0.6.1 — which profile a Devin sub-agent runs

A Devin `run_subagent` call was classed `delegate` with no canonical arguments,
so a consumer could not tell a call to Devin's own `subagent_explore` from a
call to a configured sub-agent. This release names the profile.

## Highlights

- **A Devin `run_subagent` call names its profile.** `canonical_arguments`
  carries `agent`, read from the call's `profile`, as a Claude Code `Agent` or
  `Task` call carries it from `subagent_type`. The key comes from a call
  recorded by Devin 3000.11.3, which holds `title`, `task`, `profile` and
  `is_background`, so `run_subagent` leaves the spec's open question M3.

## Install

`uv tool install openaidr==0.6.1` or `pip install openaidr==0.6.1`.

## Compatibility

**Additive.** A Devin `run_subagent` call that names a profile carries
`{"agent": <profile>}` in `canonical_arguments` where it carried `{}`. A call
without one still carries `{}`. No span derivation, kind, class or session
field changed.

Beta, and no back-compatibility guarantee before 1.0. Supported hosts are
macOS and Linux.
