# 0.11.1 — Codex sessions from the desktop app stay readable

OpenAIDR now reads a Codex session in which the desktop client writes the
outputs of its own tools. Before this release, one such record withheld the
whole session.

## Highlights

- **Desktop client tool outputs are context.** The Codex desktop client writes
  the outputs of its own tools, such as a companion page, a page snapshot and an
  edit to a writing block, as `function_call_output` records. Each record has an
  item `id`, a string `output`, and no `call_id`. The reader now keeps each output
  as local-only `injected` context, as it already did for
  `codex_app.send_message_to_thread` follow-ups. The rule uses the record shape,
  not the tool name, because the client adds new tools. `docs/specs/codex.md`
  gives the rule.

## Install

`uv tool install openaidr==0.11.1` or `pip install openaidr==0.11.1`.

## Compatibility

Span identity and the session model do not change. A Codex session that 0.11.0
withheld as malformed is now read, with these outputs in `context_items`. A
`custom_tool_call_output`, a record with no item `id`, and an output that is not
a string still withhold the session. The package is beta, with no
back-compatibility guarantee before 1.0.
