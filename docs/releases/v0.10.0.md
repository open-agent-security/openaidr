# 0.10.0 — The Codex client name is recorded

A Codex session now records the name of the client that wrote it. The name is
a description only. Session identity and span identity do not change.

## Highlights

- **`Session.originator` holds the Codex client name** (ADR-0040). The reader
  copies a nonempty string from `session_meta.originator`, for example
  `codex_work_desktop`. A missing, empty or non-string value becomes `None`.
  Cold and incremental reads give the same value. The field authenticates
  nothing and gives no capability. Other kinds leave it `None`.
- **One list of readers.** `default_readers` and `default_incremental_readers`
  now build their readers from one tuple. A new kind cannot reach one pass and
  miss the other. The readers and their order do not change.

## Install

`uv tool install openaidr==0.10.0` or `pip install openaidr==0.10.0`.

## Compatibility

Beta, no back-compat guarantee before 1.0.

- **Span identity does not change.** Session IDs, span IDs, agent kinds and
  the `(server, tool)` split are the same as in 0.9.0.
- **`Session` has one new field with a default.** It is the last field, so
  positional construction does not change. The field is not in
  `public_descriptor()` or in the default JSON output.
- **Dependencies are unchanged.**
