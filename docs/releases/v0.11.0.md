# 0.11.0 — Pi and OpenCode sessions, and file edits that carry what they removed

OpenAIDR now reads two more agent kinds, `pi` and `opencode`. A file edit's canonical arguments
now give the removed text as well as the added text. A repeated turn key now
gives a span with a `.<n>` suffix, not a `#<n>` suffix. This release also has
the 0.10.6 changes, because 0.10.6 was not published.

## Highlights

- **Pi sessions** (`pi`). The reader reads the JSONL session files that Pi
  writes under `PI_CODING_AGENT_DIR`, else `~/.pi/agent`. Each session has its
  turns, tool calls, results, tool classes, canonical arguments and token usage.
  It reads every branch of Pi's session tree, because a call on a branch that a
  person left still ran (ADR-0043). `OPENAIDR_PI_ROOT` overrides the folder for
  the CLI, and `PI_CODING_AGENT_SESSION_DIR` moves the sessions, as it does for
  Pi. `docs/specs/pi.md` gives the design and the gaps.
- **Current Pi.** The reader also reads what Pi 0.99 and later records. An MCP
  call names its server as `mcp.json` names it. The calls that a `codemode`
  script made are a turn of their own (ADR-0036). A provider's failure is an
  `error` turn. A call gets its exit code, its `durationMs` and `interrupted`
  for Pi's abort words. Usage is kept when Pi writes no `responseId`.
- **OpenCode sessions** (`opencode`). The reader reads `opencode.db` read-only,
  from `$XDG_DATA_HOME/opencode`, else `~/.local/share/opencode`. It reads the
  `session`, `message` and `part` tables (ADR-0045), and a sub-agent is a
  session of its own. Each step is one response with its usage. An MCP call is
  split against the configured server names, and stays whole when none or
  several fit (ADR-0046). `docs/specs/opencode.md` gives the design and the
  gaps. No database that a running OpenCode wrote was read.
- **A call that a Pi extension blocked reads as `rejected`.** Pi writes a
  blocked call as an ordinary error result. An extension that writes an
  `openaidr.tool-call-blocked` entry makes the call `rejected`, with
  `denial_kind` `extension-blocked` (ADR-0044). So does Pi's own reason for a
  block whose extension gave none.
- **Canonical `edits` for file edits.** A `file_edit` call with confirmed
  argument keys gives `edits`, one `{path, kind, old_text, new_text}` entry per
  hunk or file. This covers Claude Code `Edit` and `MultiEdit`, Codex and
  Cursor patches, Cursor `StrReplace`, Devin `edit` and Pi `edit`. The values
  come only from the call's own arguments (ADR-0042). Where the arguments do not
  hold the removed text, `old_text` is absent. Some tools give no `edits` key,
  because their argument keys are not confirmed. Check for the key before you
  read it. `docs/specs/session-collection.md` lists each gap.
- **Bug fixes.** The text summary no longer gives a sub-agent as the reason for
  every MCP log that was not read. It no longer says that MCP call outcomes are
  unknown when Cursor states them. The Codex reader no longer keeps compressed
  rollouts in its incremental cache.

## Install

`uv tool install openaidr==0.11.0` or `pip install openaidr==0.11.0`.

## Compatibility

Beta, no back-compat guarantee before 1.0.

- **Span identity changes for repeated turn keys only.** Claude Code and Cursor
  give a later turn with a repeated key a suffix. The suffix was `#<n>`, and it
  is now `.<n>`, because `#` starts a URL fragment. A consumer that stored such
  a span must match it again as `.<n>`. Every other span is unchanged. The
  repeat comes from a resumed Claude Code session that writes a record again,
  or a Cursor chat that repeats a message id.
- **Two new agent kinds.** `AGENT_KIND_BY_SOURCE` and `default_readers()` now
  include `pi` and `opencode`. A consumer with a closed list of kinds must add
  them. `default_readers()` and `default_incremental_readers()` take two new
  keywords, `pi_root` and `opencode_root`.
- **Additive keys.** `edits` and `old_text` are new keys in
  `canonical_arguments`. The existing keys are unchanged. A Claude Code
  `MultiEdit` also gains a top-level `new_text`, its hunks' added text joined
  with newlines.
- **Dependencies are unchanged.**
