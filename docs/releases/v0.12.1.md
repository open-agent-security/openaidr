# 0.12.1 — A smaller Cursor desktop record, with the same output

This release removes one internal field from the Cursor desktop reader. The
session model and span identity do not change.

## Highlights

- **Cursor desktop reader cleanup.** The reader no longer copies the composer
  id into its intermediate session metadata as `agentId`. No reader read that
  field. The session id still comes from the composer id, so each Cursor
  desktop session reads as before.

## Install

`uv tool install openaidr==0.12.1` or `pip install openaidr==0.12.1`.

## Compatibility

Span identity, the session model and the normalization rules do not change.
The package is beta, with no back-compatibility guarantee before 1.0.
